### **Тема: "Система управління блогами (Blog Management API)"**

**Функціональність API:**

1. **Користувачі (Users):**
   - Реєстрація та вхід (логін).
   - Отримання списку всіх користувачів (для адміністратора).
   - Перегляд, редагування та видалення свого профілю.

2. **Ролі (Roles):**
   - Дві основні ролі: 
     - **User:** може створювати, редагувати та видаляти свої пости й коментарі.
     - **Admin:** має доступ до всіх функцій, включаючи модерацію (видалення постів і коментарів інших користувачів).

3. **Пости (Posts):**
   - CRUD-операції:
     - Створення нового поста.
     - Отримання списку всіх постів або певного поста за ID.
     - Редагування та видалення постів (лише автором або адміністратором).
   - Фільтрація за датою, автором або ключовими словами.

4. **Коментарі (Comments):**
   - CRUD-операції:
     - Додавання коментаря до поста.
     - Отримання списку всіх коментарів до поста.
     - Редагування та видалення коментарів (лише автором або адміністратором).

5. **Аутентифікація та авторизація:**
   - Використання JWT для захисту ендпоінтів.
   - Розмежування доступу до функцій залежно від ролі користувача.

6. **Документація:**
   - Створення документації API за допомогою Swagger/OpenAPI.

---

**Технічна частина:**
- **Мова програмування:** NestJs (Typescript).
- **База даних:** PostgreSQL.
- **Деплой:** Docker-контейнери.
